### SETUP FOR LAB 4:

- cd react-spa-app
- Step 2: Install React Router DOM
- npm install react-router-dom
- Step 3: Replace the Source Files
- Replace the contents of the src/ folder with the files provided above.
- Step 4: Start the Application
bash:
- npm start
